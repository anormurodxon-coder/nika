NIKA

A private publishing assistant for the YouTube channel Handle (@Handle-k8h).

What NIKA does

NIKA is a personal tool used only by the owner of the Handle YouTube channel. It prepares short anime and manga news videos, sends each video to the channel owner for review, and — only after the owner explicitly approves it — uploads the video to the owner's own YouTube channel using the YouTube Data API.

  • Only one Google account (the channel owner) uses this application.
  • NIKA only uploads videos (youtube.upload scope). It does not read, edit or delete other content.
  • Every upload requires a manual human approval.
